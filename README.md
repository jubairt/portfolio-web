# Personal Portfolio Website

A responsive personal portfolio website built using HTML, CSS, Bootstrap, JavaScript, and jQuery to showcase web development skills, projects, services, and contact information. :contentReference[oaicite:0]{index=0}

# Project Overview

This project is a professional portfolio website designed to showcase:

- Personal introduction
- Skills and services
- Projects
- Contact information
- Social media links
- Frequently asked questions

The website includes smooth scrolling, responsive layouts, animations, and interactive UI components.
